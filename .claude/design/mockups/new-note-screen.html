New note

Where "Make a note" and "Send one back" lead: a square, widget-shaped note you draw or photograph, decorate and send to Sam. Approved v4, revised for Adam, 28 October 2026, built from decisions D1–D27, Adam's answers A1–A6 and layout changes L1–L3. In v4 Adam rewrote D7–D8 to send through the outbox, which supersedes L3.

Every phone is an iPhone 11 at 414 × 896 pt. The photo is an illustrated placeholder. Each phone is labelled light or dark; use the switch to see every state in one mode.

5 · Text tab, keyboard up

LightD18D19–D20A2A3L1
  • The in-call text tool: field and Add on one row, 30 characters. Changed: the same 10 colour dots as Draw in a single row that scrolls sideways (the last dots are cut by the edge), and four font chips on their own row under it, each label set in its own font (Handwritten is Noteworthy).
  • While typing, the tools ride on the keyboard (like N1 in calls). They are 164 pt tall and leave the top 272 pt of the canvas visible (68%). The canvas itself is the preview: the text shows live in that visible part, in the chosen font and colour, with the Ink outline from calls.

  • Add has no sticker shadow here; Send is this screen's one. Typed text doesn't count as content until it is added.

9 · Lose-progress dialog (Retake after drawing)

DarkD9–D11A6
  • Title "Discard this note?", message "You will lose your progress if you proceed". This replaces design.md's "Keep drawing" wording, which the spec will update.
  • A system alert, so it looks native in both modes. "Discard" uses the destructive role; "Keep editing" is the cancel role and the bold default.
  • The same alert guards: switching Draw↔Photo, ✕, swipe down, and Retake when anything is on the photo.
  • Progress is any stroke, sticker, text or taken photo. With nothing on screen, or Retake with only the photo, there is no alert.
  • Discard on Retake goes back to the viewfinder; on ✕ or swipe it closes; on the toggle it switches to a blank mode.

Notes for review

Design calls the decisions didn't cover

  • Rows stay put between modes. The row above the canvas is always there (toggle on the right), so the canvas never moves when Retake appears or goes.
  • Toggle selection is a Divider disc, not yellow, so Send is the only yellow control near the top.
  • Send is the one sticker shadow on this screen. The Text tab's Add loses the shadow it has in calls.
  • Canvas Outline 2.5 pt, as on note tiles, so the white square reads on cream. It is not saved.
  • Two-row grids. Stickers and Emoji use 2 rows instead of 3 to fit under a 398 pt canvas.
  • Text rides on the keyboard and the canvas is its preview; Add drops the text where it was previewed.
  • Trash is a badge on the selected sticker's corner. There is no control bar here to hang it above, and the badge shows which sticker it removes.
  • One pen width (9 pt at screen size, as in calls). No size slider.
  • Toast after Send: a Surface capsule 12 pt above the tab bar, fade only, shown by the app so it outlives the closed screen.
  • Face pill at 40%, not tappable, VoiceOver "Face stickers, coming later, dimmed".
  • New ink colours Red #E5483B and Orange #FF8A3D (content colours like the NotePaper pastels, the same in both modes). White is plain #FFFFFF; its 2 pt Outline keeps it visible on the white canvas.
  • Haptics: light impact when a sticker lands, .success with the toast after Send. Nothing on tabs, tools, dots, toggle or shutter.

Answered

  1. Retake: Photo mode only (A1).
  2. Handwritten font: Noteworthy (A2). Serif is New York and Mono is SF Mono. The web page falls back to Caveat where Noteworthy isn't installed.
  3. Text uses Draw's dots (A3).
  4. Black removed; 10 colours (A4).
  5. Camera: last used, back the first time (A5).
  6. Dialog: "Discard this note?" plus your line as the message (A6).

Still open

  • Nothing open for this mockup. Placed text can't be edited again in v1 (Adam confirmed).

Where the skills were overruled

  • ui-ux-pro-max prefers springs and scale on press. Motion here is cross-fades and ease-outs only (D27); a press darkens the fill over 0.1 s.
  • Its "no emoji as icons" rule doesn't apply to emoji stickers, which are content. All controls use SF Symbols (drawn as stand-ins here).
  • Type is SF Pro Rounded (Nunito stands in on the web), not the skill's font picks.
